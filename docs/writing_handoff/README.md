## 展示材料怎样使用

- 首选展示：桶交接最终选例、椅子、OMOMO Push / Pull / Kick。桶 A/B 另有补充片段；小桌放在行为分析组。
- 每组包含一段完整 MP4、6 张原分辨率 PNG、1 张六宫格和来源 manifest。MP4 为 1280×720、25 fps，由原 50 Hz 状态等间隔取样，保持正常速度；没有插值、姿态平滑、动作修补或剪掉失败阶段。
- 这些是已保存的 **Isaac 物理评测回放重新渲染**，不是新训练、参考动画或 MuJoCo 重新仿真。镜头跟随两机器人和物体的中心；地面、光照仅用于显示，不代表替换了训练场景。
- 在 Mac 解压后，用浏览器打开 `docs/writing_handoff/media/index.html`；视频也可单独用系统播放器打开。无需 Ubuntu、GPU、Isaac 或 Viser 服务。
- 素材为明确选择的完整回合。全部回合的结果见证据包，选例不会替代整体评测；Push 尤其需要结合 13050 的 1/9 记录。
- PNG 可以作为排版原料，六宫格用于快速预览。页头保留帧号、时间和模型标签，正式排版可重新组织，但保持实验身份与时间一致。

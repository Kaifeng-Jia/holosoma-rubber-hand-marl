## 通用规格（每张渲染图都适用）

1. **画幅和格式：** 2560 × 1440，PNG，无损。能开抗锯齿或超采样就开。
2. **风格：** 沿用 U5_media 的流水线：Unitree G1 原色、浅蓝物体、棋盘地面。
   - 去掉画面四角的暗角（现在的图四角很黑，裁剪后很难看）：地面亮度尽量均匀，背景用浅灰或白。做不到就原样出，并在 README 里说明。
   - 两台机器人都用原色，不上色。
3. **取景：** 所选时刻里，机器人和物体合起来至少占画面高度的 55%。同一行（同一段动作的几个时刻）用同一个机位，机位不随时间动。
4. **人的渲染：** SMPL-X 网格，灰色，和配对的机器人图同一机位（人和机器人的缩放关系照 `system1/t14/human_render.py` 的做法）。
5. **每张图配三个附带文件，同名不同后缀：**
   - `*.seg.png`：分割图，像素值区分 机器人 0、机器人 1、物体、人、地面和背景（编号写进 README）。云端用它抠图。
   - `*.json`：机位（位置、朝向或 lookat、视场角）、参考或回合的帧号和时间、所用文件的 sha256，以及下面这些点在图上的像素坐标 (u, v)：物体中心、两台机器人的左右手掌点和骨盆、（有人时）人的左右手掌点。被遮挡的点另记 `occluded: true`。
   - 同一机位下**物体中心在整段动作里每一帧的像素坐标**（画轨迹用），只在每行的最后一个时刻给一份，格式同 U5 的 `F3_traj_*.json`。
6. **不挑回合。** 用下面每组写明的规则选回合和帧；规则选出来的效果不好也照出，并在 README 里说。
7. **交付：**
   - 原图和附带文件：传 Drive `DuetMimic_transfer/T15_figures/<组名>/`，sha256 和大小记在 `results_system1/T15_figures/drive_manifest.csv`。
   - 预览：每张图另存一张宽 1280 的 JPG（质量 85），放 `results_system1/T15_figures/preview/<组名>/`，提交到 GitHub。云端先看预览。
   - `results_system1/T15_figures/README_CN.md`：每张图用的回合、帧、机位、和本任务书的偏离。只写事实。
8. **做不到的项**（例如分割图、去暗角）：停下回报这一项，其余照做，不换成别的做法。

## A. 手掌级接触的特写（论文图 3b，最先做）

用途：同一帧、同一视角下，人手、OmniRetarget 原样、我们的最终求解三者并排。

- **参考：** T14 第 6 轮 C 的 1.0 倍参考，以及同一段示范的 OmniRetarget 原样结果（`comparisons.csv` 里的 `omni_asis`）。任务：Table Transport、Chair Righting、Table Pushing 三个。
- **帧：** 每个任务取人手接触段的中点那一帧（接触段按第 6 轮的口径；左右手接触段不同时，取机器人 0 右手的）。
- **每个任务出 3 张，同一机位：** 人（SMPL-X + 物体）、OmniRetarget 原样的机器人、我们的机器人。
  - 机位照 `human_render.py` 现有的手部特写：对准两手腕中点，框住两只手 ±0.15 m；机器人图里隐藏另一台机器人。
  - 每张的 JSON 里另记：这一帧的三维接触位置误差（cm）和手掌法向夹角（°），取值和 `step6/levels.csv`、`contact_error_3d` 同一口径的逐帧值。
- 另出每个任务一张**全身**的同机位三联（人、原样、我们），机位能看到手和物体的整体关系。

## B. 前后搭档（论文图 3c 和图 1）

用途：示范者正着走，补出来的搭档面对他、倒着走。

- **参考：** 冻结的 9g2 构造，`sub12_plasticbox_053`，1.0 倍（四只手都在对应的面上）。
- **时刻：** 抱起、走路中段、放下，取帧规则同 `results_system1/T14_frontback/README_CN.md`（箱子高度第一次比第 0 帧高 2 cm；两台骨盆平均水平位移第一次达到全程一半；箱子高度最后一次比末帧高 2 cm）。
- **机位：** 侧视，视线垂直于走路方向，水平略俯（10–15°），三个时刻同一机位，能同时看到两台机器人的脚。
- **每个时刻出 2 张：** 人（示范者，单人 + 原始箱子）、两台机器人 + 加长箱子。
- **另出一张叠影：** 两台机器人在走路段等间隔 5 个时刻的姿态叠在同一张图里（前 4 个半透明，不透明度 35%），同一机位。做不到叠影就给这 5 个时刻的单张和分割图，云端来叠。
- JSON 里另记：这段参考的接触保持率、支撑脚漂移最大值（`step9_final/clips.csv` 里这条片段的值）。

## C. 只用跟踪器为什么不行（论文图 4）

用途：同一个初始状态下，SONIC 单独执行（方案 A）和 DuetMimic（D）的对比。

- **任务：** Table Transport。
- **选回合（规则）：** ±2 档里，D 种子 721 完成的第一个扰动状态（按 state_id 排序）；A 用同一个初始状态。两者都用已有的最终评测设置重放一次并保存轨迹；已有轨迹就直接用。
- **时刻：** 这个回合里 A 终止的那一步记为 t_A。取 4 个时刻：0、t_A/2、t_A、以及 D 的回合末尾。A 一行在 t_A 之后没有画面，第 4 格留给云端处理（出 t_A 那一帧即可）。
- **每个时刻每种方案出 2 张，同一机位：**
  - 只有执行（机器人和桌子）；

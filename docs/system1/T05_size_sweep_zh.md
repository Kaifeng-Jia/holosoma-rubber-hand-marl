# T05：物体尺寸扫描（2026-11-10，已取消）

**状态：已取消，不要执行。** 同一任务内改物体尺寸，主要考验的是参考生成，和本轮要检验的"控制方案能否用上力"关系不大。尺寸这个维度改用六个任务本身的物体差异来讨论。下文只作记录。

## 目的

看四种方案各自能应付多大的物体。只改物体尺寸，质量不变。

## 核心约定：不重新重定向

**只改桌子的长度。** 高度和宽度不变。

**参考不重新生成，用平移得到。** 每台机器人的整段参考，沿桌子长度方向做一次刚性平移。平移量取该机器人手部锚点在缩放后的位移均值，也就是只做平移的配准，相当于角色等距的平移部分。

**这样做的好处：**
- 手和桌面的相对关系不变，参考质量与原尺寸相同；
- 不引入新的重定向误差。

## 设置（事先定）

- **任务：** 在 Table Pulling 和 Table Transport 中选一个。
  - 选择标准：两台机器人的手部锚点都落在桌子长度方向的两个端面上。
  - 两个都符合时，选 Table Pulling：它同时在 T03 和 T04 里，而且平移就是角色等距本身要做的事。
  - 两个都不符合时，停下回报。
- **长度缩放：** 沿桌子长度方向缩放 s = 0.8 和 1.2 两档。s = 1.0 是现有的点。
- **质量：** 不变，Pull 20 kg，Table 5 kg。
- **惯量：** 按新几何重新计算。
- **物体轨迹：** 物体中心轨迹不变。

## 第一阶段：构造参考（只用 CPU，现在就可以开始，和其他任务并行）

1. **确认锚点位置。** 从论文参考和锚点数据里，确认两台机器人的手部锚点在哪个面上，然后按上面的标准选任务。
2. **生成缩放后的物体 URDF。**
   - 几何只沿长度方向缩放，质量不变，惯量重算。
   - 用开关控制，开关关闭时行为不变。
   - 从仿真里读回质量和惯量，写进 manifest。
3. **平移参考。**
   - 对每台机器人、每个尺寸，按上述规则算出平移量 t_i。
   - 把 t_i 加到该机器人整段参考的根部位置和 body 位置上（物体坐标系下沿长度方向），关节角不变。
4. **检查（门槛，事先定）。** 每个尺寸都要满足：
   - 每帧"手–锚点偏移"与原尺寸的差，最大不超过 1 cm；
   - 两台机器人任意 link 之间的最小距离大于 5 cm；
   - 手不穿进桌面。
   - 交逐项数字。任何一项不过，就停下回报，不要改阈值。
5. **初始状态文件。** 按论文规则生成 ±2 和 ±8 两档：生成种子 241003；±8 档由 ±2 档的同一组均匀抽样乘以 4 得到。记录 sha256。

**第一阶段做完后：** 交返包，然后直接进入第二阶段的评测部分，不用等回复。

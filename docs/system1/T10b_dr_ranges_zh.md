# T10b 试点的域随机化：项目、范围和依据（2026-11-20 第一版，Kevin 已确认）

## 为什么要改

T10b 冒烟测试用的随机化，是按通用的足式运动经验设的：
- 摩擦取现值的 0.5–1.25 倍，而且只改橡胶手和物体；
- 质量 ±20%、PD ±10%、延迟 0–1 步。

这套范围来自 legged_gym 和 holosoma 的 locomotion 预设，不是全身跟踪任务的做法。Kevin 要求随机化的项目和范围都要有依据，不能随手设。

## 建议的随机化（D 和 C-in 用同一套，保证两个方案的训练条件一致）

### 1. 机器人：沿用 SONIC 和 BeyondMimic 的全身跟踪做法

每台机器人各自抽样。

| 项目 | 范围 | 依据 |
|---|---|---|
| 所有连杆的材质摩擦（含脚和橡胶手） | 静 U[0.3, 1.6]，动 U[0.3, 1.2] | SONIC、BeyondMimic 原值。原来只改手，现在改成所有连杆，和它们一致 |
| 恢复系数 | U[0, 0.5] | 同上 |
| 躯干质心偏移 | x ±2.5，y ±5，z ±7.5 cm | OmniRetarget（G1 带物体）原值。SONIC 的范围更宽，但它不带物体 |
| 默认关节角偏移 | ±0.01 rad | 三篇相同 |
| 推扰 | 每 1–3 s；线速度 x、y ±0.5，z ±0.2 m/s；角速度 roll、pitch ±0.52，yaw ±0.78 rad/s | SONIC Table 4 的逐分量值，也就是 holosoma 带物体 WBT 预设的默认值。OmniRetarget 只写了"0.3 m/s、0.78 rad/s"，没给逐分量的值；按它字面逐分量取，roll、pitch 会比所有有记录的做法强 50%，所以改用有完整记录的这一套（2026-11-20 修订） |
| PD 增益 | ±10%（kp、kd） | holosoma locomotion 预设、decMHT。理由：T10 的设置对照表显示，MuJoCo 和 PhysX 的关节电枢、阻尼、摩擦本来就不同，PD 随机化覆盖执行器层面的差别 |

### 2. 物体：沿用 OmniRetarget 和 holosoma 带物体的预设

| 项目 | 范围 | 依据 |
|---|---|---|
| 材质摩擦（同时作用于物体对地面、物体对手） | 静、动 U[0.1, 0.6] | holosoma 带物体的 WBT 预设原值。现值 0.5 在范围内 |
| 恢复系数 | 不随机，保持 0 | 我们的任务没有碰撞弹跳；holosoma 预设的 U[0, 1.0] 是给小物体用的 |
| 质量 | ±20%，惯量随质量同比缩放 | 相对幅度在 decMHT 的范围内（±50%）。不取更大，是因为 T04 显示质量翻倍时 D 会明显掉点，±20% 是"同一个物体的测量误差"这个量级，不是换一个物体 |
| 质心偏移 | ±0.08 m | OmniRetarget 原值 |
| 惯量 | 50–150%（在质量缩放之上） | OmniRetarget 原值 |

### 3. 去掉的项

**动作延迟（0–1 步）：** 这次的目标是 sim2sim，MuJoCo 里本来就没有延迟。SONIC 和 BeyondMimic 都不用，OmniRetarget 明确不用。真机那边会按自己的硬件重训，到时再加。

### 4. 不变的项

**观测噪声：** 原训练配置里已经开着，不动。

## 手和物体之间的实际摩擦

PhysX 按平均值组合手和物体的摩擦：
- 在上面的范围下，实际摩擦是 0.2–1.1，中位约 0.65；
- 现在是 0.75，MuJoCo 里也是 0.75。

下限 0.2 偏低。用夹持的方式抬物体会很难，可能拖慢训练。如果试点前 8000 轮学不起来，再讨论要不要把下限收窄。这个判断只看 Isaac 验证集，不看 MuJoCo。

**Kevin 确认（2026-11-20）：** 不做特殊设计。各项范围照同类工作的原值；摩擦的组合方式保持 PhysX 和场景现有设置，不按接触对单独定范围。

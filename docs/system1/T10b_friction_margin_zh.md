## A. 摩擦余量测试（只评测，不训练）

**只改橡胶手的材质摩擦。** 改的是手掌和手指的碰撞体，其他材质都不动：物体、地面、机器人其余连杆照旧。

PhysX 里手和物体之间的摩擦按平均值组合：物体是 0.5，手现在是 1.0，所以实际摩擦是 0.75。

| 档位 | 手的材质摩擦（静 / 动） | 手和物体之间的实际摩擦 |
|---|---|---|
| 现状（已有，不重跑） | 1.0 / 1.0 | 0.75 |
| 低 1 | 0.75 / 0.75 | 0.625 |
| 低 2 | 0.5 / 0.5 | 0.5 |

- **先核对：** 手的连杆在 PhysX 里确实用这种组合方式，而且改动只落在手的碰撞体上。从 `--sim2sim-dump` 导出的场景参数里读出来，写进返包。核对不了就停下回报。
- **策略：**
  - D：Push、Pull、Kick、Chair、Bin、Table；
  - C-in：Pull、Table、Bin；
  - 都是 721、722、723 三个种子。
- **只跑 ±2 档。** 50 个回合，nominal 单独列。
- **协议：** 其他和 `results_system1/T03/d_final_5070/` 完全相同。用本机 5070；T09 如果还在跑，优先给 T09。
- **顺序：** Bin、Table 先做，然后 Pull、Chair、Push、Kick。
- **Kick 的说明：** Kick 主要用脚接触物体，改手的摩擦对它影响可能很小。照常跑，结果照实写。

**交付：** 放在 `results_system1/T10b_friction_margin/` 下：

## B. 随机化重训：准备，加一个试点

1. **复用 holosoma 现有的随机化项。** 先列出已有哪些，没有的再加，加的放在 `system1/` 下，带开关，关闭时训练行为不变。要覆盖：
   - 手和物体的摩擦，以及物体和地面的摩擦；
   - 物体质量；
   - 机器人 PD 增益（±10%）；
   - 观测噪声；
   - 动作延迟（0–1 个控制步）。

   范围先按常用值：摩擦是现值的 0.5–1.25 倍，物体质量 ±20%。范围写进返包。
2. **配置：** D 版和 C-in 版各一份，各基于现有的最终训练配置，只加随机化。
3. **冒烟测试：** 每份配置在 5070 上跑 50 次迭代，确认：
   - 能跑，没有 NaN；
   - 随机化确实生效（打印几个回合实际抽到的参数）。
4. **试点训练：云端两个 run，冒烟测试过了就开，不等 A 的结果。** GPU 由 Kevin 提供（2026-11-20），每个 run 一张卡。
   - **D Table，种子 721：** 随机化打开，其余设置和论文的 D Table 相同，迭代数也相同。
   - **C-in Bin，种子 721：** 随机化打开，其余设置和 T03 的 C-in Bin 相同，迭代数也相同。
   - 选这两个的原因：T10 里各自方案掉得最多（D Table：Isaac 130 → MuJoCo 0；C-in Bin：135 → 0）。这个选择是事先定的，不是看结果挑的。
   - **冒烟测试通过后先回报，** 由 Kevin 开云端机器，免得机器空转。
   - 云端的环境、代码版本和同步方式，沿用 T03 / T04 在云端训练时的做法。不自己开、也不自己续租付费资源。
5. **试点训完后：**
   - Isaac 里按 `d_final_5070` 的协议评测，±2 和 ±8；
   - MuJoCo 里按 T10 的设置和协议评测，±2 和 ±8；
   - 和原策略（D Table 种子 721、C-in Bin 种子 721）并排比较。

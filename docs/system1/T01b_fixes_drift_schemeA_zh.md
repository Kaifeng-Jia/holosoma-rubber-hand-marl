## 一、修复与核查（方案 A 正式评测前全部完成）

每一项交一个结果文件；任何一项不通过，就停下回报。

- **F1：双机器人驱动的等价性。**
  - 验证 a、b 用的是单机器人 WBT 环境，正式评测用的是 `SonicDualDriver`，这段代码还没有被验证过。
  - **离线检查（门槛）：** 构造同一组机器人状态和参考帧，分别经过双机器人路径和单机器人路径，生成 SONIC 观测和动作。TF32 关闭时，两条路径的最大差 < 1e-6。
    - 同时核对：机器人 0 收到的参考关节向量，与 npz 里 agent 0 在同一帧的值逐位相同；机器人 1 同理。
    - 换回 holosoma 动作后，`[E, A×29]` 的排布与动作项期望的排布一致。
  - **在线记录（不设门槛）：** 在双机器人环境里把物体移出场景，或关掉物体的碰撞；两台机器人各跟自己的角色参考。每台机器人的 MPJPE 和漂移，与单机器人环境跟同一段参考的结果并列报告。
- **F2：冻结动作缩放。**
  - holosoma 按 `0.25 × 力矩上限 / Kp` 计算动作缩放。换上 SONIC 的 hip_pitch 增益后，缩放会从 0.5475 变成 0.222。这会影响 C 训练时的奖励（动作变化惩罚）和"上一步动作"观测。
  - **改法：** 加一个开关，使 SONIC 方案只替换 PD 增益，动作缩放保持论文的值。
  - **验收：** 在 run_config 和评测 manifest 里，hip_pitch 的 Kp = 99.10、动作缩放 = 0.5475；SONIC 给出的 q* 与 PD 实际收到的目标最大差为 0。
- **F3：关闭 TF32。**
  - 正式评测和 C 的评测一律关闭 TF32（`torch.backends.cuda.matmul.allow_tf32=False`，`cudnn.allow_tf32=False`），使结果与并行环境数无关。
  - 在 TF32 关闭的状态下：
    - 重新导出 SONIC 原生运行的观测和动作，与我们加载的网络对比动作差。预期降到约 1e-5；如果没有降，停下回报。
    - 在 GPU 上重做验证 a（标准不变：≤ 1.2 × 原生值，且不摔倒），以及验证 b。
  - 另外检查：同一批输入分别以 batch = 1、2、128 推理，动作完全一致。
- **F4：body 名对应。**
  - 断言参考数据里 pelvis、SONIC 的 14 个跟踪 body、4 个末端 body 的名字和下标，与仿真 `_body_list` 中的逐一对应。断言写进代码。
- **F5：按环境重置（为 T03 准备）。**
  - `SonicController.reset(ids)` 只清空指定环境的历史；`act_inference` 收到逐环境的 `dones`。
  - **测试：** 一批 8 个环境，第 3 步只重置其中 2 个；其余 6 个的动作与不重置时逐位相同（TF32 关闭）。
- **F6：训练配置 diff。**
  - 每个新训练开训前，run_config 都要与对应的论文 run 做逐字段 diff：Table 对照 T-07 seed721，Bin 对照 B-RZ0 seed721。
  - 只允许质量、种子、目录、运行元数据不同。Pull 已经做过。

## 二、漂移分析（只评测，不改设置，本机 GPU，TF32 关闭）

先把定义和判定规则写进 `results_system1/T01b/preregistration_drift.md` 并提交，再开始算。

- **(i) SONIC 跟踪全部 12 段角色参考**（6 个任务 × 2 台机器人），单机器人、无物体、从第 0 帧开始。每段报告：
  - 全局 MPJPE、相对骨盆 MPJPE；
  - 骨盆水平漂移：末帧值和最大值；
  - 漂移速率，两种口径：cm/s，以及每米参考行程的漂移（cm）；
  - 把实际位移和参考位移分解为沿行进方向和横向两个分量，逐秒记录。
- **(ii) 参考本身的脚滑。**
  - 对象：上述 12 段参考，加上 SONIC 的两段示例动作作为基准。
  - 着地判定事先写进预登记文件，例如脚底高度阈值。
  - 统计着地期间脚的水平滑移总量，以及每米骨盆行程对应的滑移量。
- **(iii) 对照组。**
  - 用三个单人任务（Push、Pull、Kick）各自的单机器人先验（D 的 actor 初始化 checkpoint，不经过 SONIC），在同一设置下跟踪各自对应的角色参考，报告与 (i) 相同的指标。
  - 两人任务没有单人先验，写"不适用"。
- **(iv) 漂移和脚滑的关系。**
  - 画漂移速率对脚滑量的散点图：12 段参考加 2 段 SONIC 示例，所有点都画，不剔除。
  - 报告 Pearson 和 Spearman 相关系数，以及样本数。
- **(v) 排查接入问题。** 如果发现方向反了、帧率或坐标系不一致，停下回报。

# T04：物体质量扫描（2026-11-09 第二版）

## 目的

看四种方案各自能搬多重。只改物体质量，其余一律不变。

## 档位（事先定，全部报告）

每个任务都从原质量往上翻倍三次。

| 任务 | 档位（kg） | 原质量档 |
|---|---|---|
| Table Pulling | 5、10、20、40 | 20 |
| Table Transport | 2.5、5、10、20 | 5 |
| Bin Transport | 1、2、4、8 | 1 |

- **只改质量：** 惯量按质量同比例缩放，几何不变；摩擦、尺寸、参考、初始状态都不变。
- **读回记录：** 每个档位开训或评测前，从仿真里读回物体的实际质量和惯量，写进 run_config 或 manifest。
- **Bin 的 URDF：** 如果不是单个 link，现有的 `mass_variants.py` 会报错。这时停下回报，不要自行改动。

## D 部分（不依赖 SONIC，云端复现验证通过就开训）

- **run 数：** 每个任务的 3 个新档位各训练一个 run，种子 721，共 9 个，并行执行。
- **配置：** 与该任务的论文 D run 逐项相同，只改质量、种子、目录。
  - Pull：V3 Full-rerun，先验初始化，50 + 8000；
  - Table：T-07 seed721，fresh 12000；
  - Bin：B-RZ0 seed721，fresh 12000。
- **开训前：** run_config diff 只允许上述几项不同（F6）。
- **剔除规则：** 同 T03。
- **本机中止的 run：** 本机已经中止的 Pull 5 kg 不使用，在云端从头训练。

## A、B、C 部分

- **A：** 所有档位直接评测，不训练。
- **B：** 新版 T02 定稿后，所有档位直接评测。
- **C：** T03 的三个 721 run 都满足以下条件后，在各新档位各训练一个 run，种子 721，共 9 个。配置与 T03 相同，只改质量。
  - smoke 正常；
  - 训练超过 1,000 次迭代；
  - 没有出现 NaN。

## 原质量档用哪个点

- 扫描曲线统一用种子 721：
  - D 用论文 seed721 的主结果；
  - C 用 T03 的 721 run。
- 原质量档另外标出 D 三个种子的范围。

## 额外评测（便宜，顺带做）

## 2. 观测 v1 和噪声 v1

只用于 R1、R5、R10。critic、奖励、终止、动作都不变。

**actor 观测（每台机器人）：**
1. 不变：上一步动作 29、骨盆角速度 3、关节位置 29、关节速度 29、参考关节位置和速度 58。
2. **参考躯干朝向 6：**公式不变；计算时，实际躯干朝向的偏航加上"航向偏差"，横滚、俯仰不加。
3. **同伴相对位置 2：**同伴颈后点减去自己颈后点，取水平分量，转到自己的航向系（带航向偏差）。
   - 截断沿用 ±1，记录训练中被截断的比例。
   - 颈后点 = torso_link 上的一个固定点，取颈后原厂把手的位置。从 URDF / 网格估计，写进配置，报告里给出坐标。
4. **删掉**同伴相对速度 2。
5. **新增物体相对位置 3：**物体根坐标原点减去自己颈后点，转到自己的航向系（只转偏航），截断 ±2 m。

合计 159 维。

**噪声 v1（R1、R5 训练时开；R10 全程关；验证和评测默认关）：**
- **颈后点：**每回合一个固定偏移，x / y / z 各自均匀 ±3 cm；再加每步均匀 ±1 cm。两台机器人各自独立。
- **物体点：**每回合一个固定偏移，各轴 ±2 cm；每步 ±1 cm。
- **航向偏差：**每回合一个固定值，均匀 ±5°；两台机器人各自独立。
- 其余项沿用现有噪声。不加延迟。
- 这些数是 v1，之后按动捕参数更新。在配置里集中放一处。

**检查（不通过就不开训）：**
- 观测维数和顺序正确；
- 关掉噪声时，新观测和按定义手算的结果一致（误差 ≤ 1e-5）；
- 开噪声时，各项偏差的分布符合设定；
- 200 次迭代的 smoke 正常。

**MuJoCo 端：**最终评测前，补上观测 v1 的构造，按 T10 的门槛检查：初始状态；观测和 Isaac 录到的逐维比较（≤ 1e-4，噪声关）；ONNX 用 float64 判定。

## 3. 训练协议（所有 run）

- **checkpoint：**每 1000 次迭代存一个。
- **验证集：**
  - Table、Bin 沿用 T10b 的验证集；
  - Kick、Pull、Push、Chair 新生成：同一个生成器，种子 20261120，±2 档，各 50 个，和测试状态无重复，记录 sha256。
- **验证：**每 2000 次迭代在 Isaac 里评一次。确定性动作，随机化关，噪声关，协议同 `d_final_5070`。
- **停止规则：**记 B 为该方案、该任务原论文 run 的迭代预算。
  - B − 4000 以后，如果验证集完成数连续 4000 轮没有超过此前的最好值，就停；
  - 这 4000 轮的观察窗口要整个落在 B − 4000 之后，所以最早在 B 那次验证之后停；
  - 否则训到 B + 8000；
  - 最终用停下时的最后一个 checkpoint；
  - B = 12000 时，规则和 T10b 的 D Table 试训完全一致（8000 / 12000 / 20000）。
- **只用验证集决定什么时候停。**测试状态和 MuJoCo 的结果都不用。
- **出错处理：**崩了从最近的 checkpoint 续跑一次；再崩就停下记录，这张卡让给队列里的下一个。

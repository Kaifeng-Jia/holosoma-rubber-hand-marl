## 3. 训练协议

- **checkpoint：**每 1000 次迭代存一个。
- **验证集：**R1 沿用 T10b 的 Table 验证集；R2 见第 1 节。
- **验证：**每 2000 次迭代在 Isaac 里评一次。确定性动作，随机化关，噪声关，协议同 `d_final_5070`。
- **停止规则（B = 12000）：**8000 轮以后，如果验证集完成数连续 4000 轮没有超过此前的最好值，就停；这 4000 轮的观察窗口要整个落在 8000 之后，所以最早在 12000 那次验证之后停；否则训到 20000。最终用停下时的最后一个 checkpoint。和 T10b 的 D Table 试训完全一致。
- **只用验证集决定什么时候停。**测试状态和 MuJoCo 的结果都不用。
- **出错处理：**崩了从最近的 checkpoint 续跑一次；再崩就停下，记进状态文件。

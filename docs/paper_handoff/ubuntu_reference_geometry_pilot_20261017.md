# 第二版 B：交互结构迁移与 Procrustes 离线试验

请在现有 Ubuntu 项目中执行这份任务。作者已认可尝试此方向；当前目标是确定对应规则、实现最小参考生成原型并检查结果。只使用既有 Push / Pull，不训练策略、不改奖励、不覆盖正式参考或第一版结果。先 Push 后 Pull；一个案例遇到输入或对应歧义时，保留诊断并继续另一案例能独立完成的部分。

## 1. 要实现的机制

从单机器人源参考提取手—物局部交互结构，在目标物体上建立角色区域对应，使用加权正交 Procrustes 求每个角色整段共用的正交变换和平移，再将参考映射到真实机器人并检查两个角色是否兼容。

该原型允许旋转、平移及反射；负行列式的几何变换必须通过现有双侧反射和关节映射实现，不能直接作为机器人根部旋转。角色对应来自真实物体几何或明确记录的角色区域输入，不能根据旧间距、旧外移量或旧双机器人输出反造目标。

优先复用当前仓库的模型加载、FK、四元数、关节镜像、速度计算和参考导出接口。新增内容写入独立原型模块及独立结果目录，不修改正式配置。记录实际 Git 状态及局部改动，勿为了凑预期结果改源动作、物体轨迹或腕部配置。

## 3. 先得到可解释的交互区域和对应

### 3.1 真实几何与手部点

解析源、目标物体的实际碰撞几何及origin变换。为部件与外露面建立稳定ID：部件类型、中心、尺寸、面法向、边界、邻接关系；例如桌面和四条腿的不同盒体。排除盒体相交内部的不可见面，不将一组未合并盒体的内部面当可交互表面。

使用实际`left_rubber_hand_link`、`right_rubber_hand_link`的FK及表面点；腕部原点不能当接触点。冻结描述中两手相对腕部有非零偏移，训练侧固定链接可能被合并，须用同一模型核对世界变换。可用确定性的表面采样；保存采样点及其手部局部坐标。拟合区域提取用一组点，验收另用独立的稠密采样或网格距离。

### 3.2 源候选交互时段

先计算源手表面到源物体真实外表面的逐帧距离、最近部件/面、近邻点占比；保留有符号穿透诊断。称其为“候选交互”，没有接触标签时不要称真实接触。

工程起始规则：到真实外边界的**无符号距离**不超过3cm、每手至少5%的采样点满足邻近、持续不少于0.1秒，允许填补一个采样帧的间断。有符号距离另存为穿透诊断，不能直接用`signed_distance <= 0.03`把深穿透点都算作邻近；也不能因邻近计算使用无符号值而丢弃穿透记录。以上只是v0起始阈值，不是已验证的论文参数。先根据源几何与距离曲线检查一次；需要调整时，只依据源数据和模型分辨率调整并保存理由，随后冻结，不能看新候选成绩再调。

按手身份、连续时段及部件/面关联组织记录。表面边界处若存在竞争关联，保留候选和歧义，不逐帧任意跳面。不得把没有稳定邻近关系的片段强行标注成接触。源近邻关系完全无法辨认时输出距离曲线和全身/手部图，标记`needs_interaction_regions`。

### 3.3 源锚点与目标候选：双手共同构成一个角色

每个活跃手/时段保留其关联物体部件和有限面。优先使用实际部件的面角点或边端点作为可对应的几何锚点；也可使用已明确有边界的交互区域角点。使用米制真实坐标，不各自归一化尺寸，不加自由缩放来消除目标宽桌与源桌差异。

同一角色的两只手、多个交互时段联合建立一个有序部件/面tuple，最终只求一个共同变换。不能给两手分别做最佳配准后拼成一个身体。保留“一只手对应哪个部件/面”的语义；反射分支须明确源左手对应伙伴右手，源右手对应伙伴左手。

目标候选从同类真实部件/面及其邻接关系产生：

1. 枚举与源tuple相容的目标部件tuple，保持共同部件/不同部件关系和两手的整体几何。同一源部件上的不同面必须映射到同一目标部件；不同源部件的映射保持一对一。同一源面被双手或多个窗口引用时，在同一角色内其目标面及角点顺序也必须相同，不能按窗口改对应。
2. 以真实长宽、法向类别和部件间距离做可记录的几何预筛；不将不等距形状强行当同构。
3. 矩形面可枚举有限的角点顺序（D4对应），但必须一致维护手身份和角色奇偶分支，并在求解后检查面外法向。不能逐个锚点任意最近邻重排。
4. 每个候选对应覆盖全段预先确定的源窗口，不按时间帧切换伙伴角色。

**连续桌面上的角色区域**：如果实际几何和预定角色关系不能唯一给出两个有限区域，不得悄悄选两个中心以恢复旧间距。输出`needs_role_regions`及候选区域图；允许作者/Mac随后指定区域边界或部件关系，作为明确输入。无需指定机器人位移，Procrustes仍负责求变换。这个条件可能首先出现在Push，不应因此改为旧偏移再称新方法成功。

所有候选按稳定几何ID排序并去重。先报告候选数；规模小则全部计算。若超过256个/角色，先给出组合数量与导致爆炸的歧义，收紧有几何依据的规则或返回需要区域输入，不静默截取前256个冒充穷举。优先允许两个角色使用不同但相容的区域；在同一大部件上操作本身不判定冲突。

### 3.4 在求解前保存对应规则

写入`correspondence_spec.json`，至少包含源/目标几何哈希、手身份、源窗口、部件/面ID、锚点坐标、目标候选、角点顺序、权重、角色奇偶性、人工区域输入（若有）及所有阈值。保存一张源区域和两角色目标区域示意。没有歧义时按已定规则继续，无需逐步等待批准；若语义关联无法判断，仅暂停该案例依赖部分并回传具体疑问。

## 4. 配准求解、角色组合及参考导出

### 4.1 一个角色的一次加权配准

为角色i固定目标对应后，源/目标锚点分别为$a_k,b_{i,k}$。每只活跃手获得相同总权重；每手内部按持续时间分配至各窗口，各窗口内锚点均分权重，最后归一化。两手共用部件时仍保留手身份；额外重复采样不能提高该手的总权重。

求解：

$$\min_{Q,c}\sum_k w_k\|Qa_k+c-b_{i,k}\|^2,
\quad Q^TQ=I,\quad \det Q=s_i.$$

初版沿用已定角色类别：Push两个角色为正分支；Pull源角色为正分支、伙伴为负分支。不在初版另声称自动判断任务需要何种角色关系。

对列向量约定，令加权质心为$\bar a,\bar b$，

$$H=\sum_k w_k(a_k-\bar a)(b_{i,k}-\bar b)^T=U\Sigma V^T,$$
$$Q=V\operatorname{diag}(1,1,s_i\det(VU^T))U^T,\qquad c=\bar b-Q\bar a.$$

检查公式使用的矩阵行/列约定；若库实现用行向量，必须相应转换。记录奇异值和残差。固定行列式分支时，非共线平面锚点可以求解；两点/近共线数据需返回退化标记，不靠随机扰动造满秩。v0采用$\sigma_2/\sigma_1\ge10^{-4}$作为近共线筛选，$\sigma_1$接近零单独拒绝，绝对数值容差按米制坐标与浮点精度配置。不把这一步称为求解所有接触、碰撞约束的全局最优。

### 4.2 从几何变换到真实机器人

共享物体位姿为$(p_{o,t},R_{o,t})$，源基座为$(b_{s,t},R_{s,t})$。角色位置为：

$$b_{i,t}=p_{o,t}+R_{o,t}\left[Q_iR_{o,t}^T(b_{s,t}-p_{o,t})+c_i\right].$$

正分支保留关节顺序，根部姿态为$R_{o,t}Q_iR_{o,t}^TR_{s,t}$。负分支使用：

$$R_{i,t}=R_{o,t}Q_iR_{o,t}^TR_{s,t}J,\qquad q_{i,t}=DPq_{s,t},$$

其中$J$及$DP$复用并核对实际G1的矢状面反射与左右关节映射。检查行列式、关节限位、$J$与$DP$各自双次作用的一致性，以及真实FK是否与理想映射相符。一般负行列式正交矩阵不一定满足$Q^2=I$，不要以此错误拒绝候选；几何变换的逆为$(Q^T,-Q^Tc)$，用正向/逆向检查。表面外向法向按$Qn_s$映射；反射后保留原顶点顺序直接叉乘会反转法向，需正确处理顶点绕序。非对称几何/关节限位造成的偏差需要量化，不通过只画理想点掩盖。

统一保持物体轨迹、帧数和采样时间。输出完成后用已有正确接口生成身体位置、姿态和速度；初版不重新重定向、不再加腕部优化、不逐帧调整关节或变换。源腕部处理按正式参考保留，防止同时改变两个因素。

### 4.3 双角色候选检查与选择

对所有可计算的角色候选检查法向映射、完整参考的机器人/物体相容性；再检查成对组合的区域占用与真实身体间隙。若穷举配对量过大，报告实际规模并使用明确标记的有限搜索，不将截断结果当全局最优。

重点检查：

- 手部对应面外法向是否一致，手是否仍接近目标有限区域。
- 非手部穿透、机器人之间的穿透，以及脚部穿地。
- 相对于源运动的重力方向变化。不能要求机器人永远直立：Pull源动作本身存在明显倾斜。可记录整个序列中$F_t=R_{o,t}Q_iR_{o,t}^T$对世界重力方向的偏差及源/新根部倾角；恒定物体局部Q并不自动保持重力关系。
- 在**源支撑时段**的脚部漂移，姿态及速度的突变；不要将正常迈步当脚滑。没有接触真值时使用并明确记录已有支撑代理定义。

数值合法性问题直接拒绝。物理几何筛选阈值优先沿用仓库已有定义，缺少时依据模型分辨率与源参考先给出v0配置并冻结；保留每项连续数值及失败原因，不能只返回一个pass。通过预定筛选的组合按联合加权配准误差排序；并列时使用固定几何ID，不根据看起来更接近旧间距来打破平局。无可行组合就报告无可行解。

## 5. 验证与对照

先做与真实实验无关的求解器检查：已知平移、已知反射、带权旋转/平移、共线退化、异尺度不能被刚性拟合消除。检查负分支输出的机器人姿态仍为SO(3)。合成检查只验证程序，不混入论文实验数据。

| 指标 | 评测要求 |
|---|---|
| 拟合残差、奇异值、候选数和筛选原因 | 检查求解，不能独立证明参考质量 |
| 实际机器人FK后的手表面到真实有限物体表面的距离、对应区域保持、法向误差 | 使用不同于拟合锚点的表面采样/网格，记录是否用于筛选；源交互窗口内与全序列统计分开，不要求非交互时段始终接触，不能只算理想变换点 |

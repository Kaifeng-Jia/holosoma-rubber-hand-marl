## 1. 对应构造与权重

第一批 106 个文件逐项校验通过；源参考、模型、网格、正式配置及旧 runtime 的哈希再次核验。细节见 `batch1_verification.json` 与各案例 `input_manifest.json`。

区域由实际尺寸计算：源宽 0.5219528 m，目标外界 ±0.7 m，两区间为 `[-0.7,-0.1780472]`、`[0.1780472,0.7]`。Push 使用局部 X，Pull 使用局部 Z；角色奇偶性分别为 (+,+)、(+,-)。没有输入旧间距或旧外移。

区域是实际外露面与区间的交集。裁切内边界不产生新墙面。有限面四角、外法向、实际部件中心间隔和共享角点/边关系一起约束对应；源两手关联同一条腿时目标也必须是同一条腿。模型原有桌腿与桌面的小间隙被保留，没有强制部件相接。

每角色枚举全部奇偶分支内的有符号轴次序、合法目标腿。Push 初始 24/24 个，Pull 初始 48/48 个，按尺寸、外露面存在性与部件相对几何排除不相容项。矩形面的 D4 对应由整个部件 tuple 的一致轴次序诱导；不允许逐窗口改变角点顺序或独立翻转单面。接受后的候选数如表，未截断搜索。所有尝试和排除理由保存在 `correspondence_spec.json`。

第一批窗口一条未删。每只活跃手总权重为 1/2；每个有支持的帧分配一个时长证据单位，先均分给唯一支持样本，再由一个样本的竞争面分摊这份权重，最后按窗口内角点均分。这样边角样本不会因同时邻近多个面而贡献多份证据。填补间断的原窗口保留，但无支持的间断帧不凭空增加证据。实际窗口、有效时长、锚点及最终权重均保存。

区域评测使用全部相容有限面集合，不要求手掌法向同时朝向竞争的多个面。`association_evaluation.json` 和 `*_association_checks.csv` 另分开报告确定面集合与边缘竞争集合；它们是几何邻近，不是接触力标签。

## 2. 求解结果

### Push

选出的诊断候选两角色均为 Q≈I，c 分别为 `(-0.4390236,0,0)` 与 `(0.4390236,0,0)` 米。加权残差约 1e−16 m；这是所选等尺寸区域的构造性质，不能单独证明动作质量。

相对旧 ±0.4 m 构造，每个机器人全段的基座位移差范数为 **39.0236 mm**，机器人间距增加 **78.0472 mm**。关节逐项不变，根部旋转差约 1e−15 rad，物体轨迹逐项不变。位置、速度、runtime 全通道差异见 `old_new_comparison.json` 和逐帧文件。

两角色手部有限区域关系、法向映射、数值合法性及新增手部/身体/地面筛查通过；但源支撑代理时段内的新增足部速度和漂移超过冻结阈值。因此 36 个组合中没有完整通过者；导出的最佳失败组合明确是 `diagnostic_only`，不是正式可用参考。

旧参考同样不通过该源相对脚部筛查。四个“角色×脚”中，新版最大新增支撑漂移为 **34.41 mm**，旧版为 **31.13 mm**；新旧差约 **3.28 mm**。各脚完整数值均保留。原因可从构造直接解释：固定物体局部偏移变成世界坐标 `R_object(t)c`，桌子转动时这项也变化，连同脚的位置一起改变。本轮没有逐帧 IK 或脚部补偿。不能把这类既有构造问题归结为新方法独有，也不能忽略本轮新增量。

旧 Push 的原始根部四元数还存在最大约 8.23e−8 的范数舍入误差，高于冻结的 1e−8 数值阈值，故旧版检查表另外记录了这一项；这不是显著姿态错误。新变换经旋转矩阵接口输出单位四元数；新旧姿态比较使用符号无关、归一化后的 SO(3) 夹角，未把微小表示变化当作动作改进。

### Pull

完整桌面+桌腿窗口共同求解后：源角色 Q≈I、c≈`(0,0,-0.4390236)`；伙伴 Q≈diag(1,1,−1)、c≈`(0,0,0.4390236)`。负分支使用实际 G1 左右关节映射及 J，将根部旋转保持在 SO(3)。

同 X 负侧的两端腿组合通过本轮源相对筛查，其他候选因源相对重力/脚地面/连续性等具体项目被排除。完整新参考与旧版基座位置最大分量差约 **1.11e−15 m**，根部旋转差约 **1.07e−15 rad**，关节差为 0；runtime 的实际误差逐通道报告，不用四元数符号差冒充旋转差。

结论是：**在当前确认的区域规则下，完整交互几何对应恢复了旧 Pull 参考。** 这比第一批只拟合腿子集的结论更完整，但并不表示成功率提高，也没有刻意制造不同轨迹。

## 3. 检查的准确范围

- 手部：真实 URDF FK 后每手 1024 个独立表面样本，到实际盒体并集外边界及有限目标区域的距离；符号穿透单独记录。独立于 256 个拟合样本，但这些检查参与筛选，**不是 heldout**。
- 身体—物体：每条 link 的碰撞网格局部包围盒经真实 FK 变为 OBB，与实际物体盒体作解析分离轴检查。
- 机器人—机器人：链接 OBB 对的解析筛查；选中组合的间隙下界均至少 0.1 m（记录在 0.1 m 截断，不代表精确间隙为 0.1 m）。
- 正 SAT 值是分离间隙下界，负值是代理重叠；**OBB 重叠不等于真实网格穿透**。每角色最差非手重叠处另用更紧的实际网格凸包作单帧核验，只用于诊断、不反调选择。
- 例如 Pull 第 7 帧髋部 OBB 报约 66.36 mm 重叠，但更紧凸包实际仍有约 **5.66 mm 分离下界**，因此不能把前者写成髋部穿桌。Push 第 77 帧腕部 OBB 约 16.30 mm 重叠，凸包仍约 10.54 mm 重叠；这也不是精确凹网格穿透深度。
- 源支撑代理由源脚底高度≤4 cm、XY 速度≤0.15 m/s、持续≥0.1 s 定义；比较使用相同源窗口，不将普通迈步当作脚滑。无真实接触标注，不声称它是严格支撑真值。
- 脚地面使用真实脚网格顶点和统一世界 Z=0。Pull 原回放左右脚最小高度约 −13.26/−23.63 mm；既有物体对称化/源运输后约 −60.65/−23.63 mm，选中旧/新对中全局最差约 −67.33 mm。它们被如实记录，没有平移地面或修参考以通过。**因此 Pull 不能被称为绝对脚部无穿地，只是新旧等价且新增量在本轮源相对容差内。**
- 数值/关节限位/根部 SO(3)、全身 link 原点 FK 映射误差、法向、重力偏差、姿态与速度连续性均逐项保存。未声称动力学或机器人自身内部自碰撞验收。

冻结阈值见 `frozen_screen_thresholds.json`：含 1 cm 新增身体/脚地面重叠容差、1 mm 新增手表面穿透容差、1 cm 新增支撑漂移、0.01 m/s 新增支撑速度等。它们是明确记录的 v0 工程筛查，非论文已验证参数。报告连续数值，不以单个 pass/fail 代替判断；本轮未根据结果调阈值。

## 4. 实现校验及过程中修复

第一批已通过的 8 项基础测试未重复作为新实验。新增 5 项针对性测试通过：真实区域无裁切墙、竞争证据不重复、完整窗口对应、SAT 分离/穿透符号、刚性变换不变性。完整 Pull 新旧等价姿态的代理指标最大差约 1e−15 m，回归检查通过。

初次几何距离查询路径曾对数值等价的 Pull 姿态报告不一致符号。第 289 帧一处返回约 −28.23 mm，而独立分离轴证实有 +28.23 mm 间隙。该实现路径未用于最终结论；保留本地诊断目录，最终改为可解析测试的 SAT 代理。全身逐帧精细凸包计算过重，最终全段采用 OBB 筛查，最差点做凸包核验；手部仍用真实表面样本。另修复了 runtime 元数据 JSON 序列化。没有改候选参考、区域宽度或筛选数值来得到当前结论。

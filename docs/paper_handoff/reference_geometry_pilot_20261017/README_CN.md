## 3. 已完成的独立机制检查

8 项合成测试全部通过，原始输出及退出码见 `synthetic_tests.txt`。覆盖平移、带权旋转平移、一般负行列式（不要求 Q²=I）、共线退化、尺度差不可被刚性消除、根部 SO(3)、并集内部面、窗口规则。合成测试不混入论文效果指标。

实际 G1：关节镜像 DP 和矢状反射 J 各自二次作用为恒等；源关节无限位超出；负分支根部行列式误差约 1e−15。完整帧序列的手 link 原点镜像偏差约 0.01 mm；16 个均匀帧、每手每帧 1024 个独立采样点到实际对侧手网格的最大偏差，Push 约 **0.242 mm**，Pull 约 **0.240 mm**。保留实际模型左右微小不对称，没有用理想镜像点取代真实 FK。

Pull 桌腿**子集**枚举 64 个匹配（每个奇偶分支 32 个），均为实际等尺寸桌腿及一致有符号轴对应。恒等旋转、同 X 侧的腿对应可自然得到 Z 外移绝对值 **0.4390236 m**。该值在冻结规则后与旧参数比较，未输入锚点生成器。这支持“局部几何可恢复旧外移”的假设；仍未覆盖全部桌面窗口、未筛脚地面/机器人碰撞，不是新的完整双人方案。

## 2. 已确认的角色区域规则

令加宽轴为 $u$：Push 为物体局部 X，Pull 为局部 Z。源桌面沿该轴的实际宽度为 $L_s$，目标桌面的外边界为 $u_{\min},u_{\max}$。定义两端区域：

$$I_-=[u_{\min},u_{\min}+L_s],\qquad I_+=[u_{\max}-L_s,u_{\max}].$$

从正式几何读取这些量，不输入旧机器人间距或旧外移量。当前资产得到 $L_s=0.5219528$ m、目标边界 $[-0.7,0.7]$ m，因此两区间为：

$$I_-=[-0.7,-0.1780472],\qquad I_+=[0.1780472,0.7].$$

这些数值是本轮所选几何规则的展开，不是另行优化或手调的机器人位置。保留源、目标坐标与尺寸来源，先冻结 `correspondence_spec`，再求机器人变换。本轮不增加半桌均分对照，也不依据最终结果改变区域宽度。

Push 两角色分别使用 X 负端、正端区域，均为正行列式分支；Pull 源角色使用 Z 负端区域、正分支，伙伴使用 Z 正端区域、负分支。保持第一批的源坐标和角色身份，出现与清单不一致时报告具体差异。

### 区域不是新增物体

- 目标仍是一张完整宽桌；区域仅用于定义真实表面上的对应，不切割碰撞物体、不添加几何。
- 区域内侧的裁切线不是实体侧面。可以作为有限表面区域的定位边界，不能生成垂直墙面、侧面法向或接触约束。
- 将目标真实外露面与所选区间相交，得到合法表面子区域；继续排除盒体并集的内部面。上下表面、真实外端侧面、长侧面分别保留各自身份。
- 只要求源活跃部件与相应目标局部结构建立一致对应，不声称整张源桌及其四条腿与每个端部区域全等。

## 3. 保留完整交互结构，并正确处理歧义

### 桌面和桌腿共同参与

保留第一批所有稳定窗口及其手身份、部件和面关联，不为了恢复旧外移量删掉桌面窗口。每个角色的双手与全段窗口共同确定唯一的 $Q_i,c_i$，不逐手或逐帧分别求解后拼接。

已核对的当前源桌面关联为：Push 的 Y±、Z−；Pull 的 Y±、X−、Z−。Pull 两手还关联同一源腿 `largetable_leg_neg_x_neg_z`。这些面与端部区域有几何上相容的对应；这是继续构造的依据，不是完整候选已通过验收。

Pull 每个角色的桌腿对应须属于该角色端部，并与桌面对应的外端、真实侧面及邻接关系一致；源双手关联同一条腿，目标仍须关联同一条腿。相同源部件/面在不同窗口中不得更换目标或角点顺序。保留有限候选及拒绝理由，不把第一批已求出的旧偏移作为候选生成输入。

邻接按实际模型的部件相对位置及间隙定义，不要求模型中本不相接的部件强行接触，也不为建立对应修改物体几何。

### 边缘竞争面不能当成多次确定接触

第一批保留了等距竞争面。尤其 Pull 左手桌腿 Z−、Z+ 关联的大部分支持点属于边缘等距情况；这些不是多项独立的确定接触标签。

- 保留原始窗口与完整竞争集合；不能悄悄删记录，也不能把一个边缘样本在多个面中重复计权。
- 对应选择在角色/部件层面保持整段一致。若枚举面对应分支，记录其选择并检查邻接，不以每帧任意换面降低误差。
- 配准仍按原规格分配每手总权重；对重复窗口或相同支持样本明确去重/分摊规则，保存实际权重。窗口全部保留不等于把歧义重复当成多份独立证据。
- 几何法向检查验证所选源/目标表面之间的 $Qn_s$ 一致性。不要要求同一个手掌法向同时对齐所有竞争面；未定义实际接触朝向时，不把这种要求作为淘汰条件。
- 在区域保持评测中明确区分确定面关联与边缘集合关联；后者按记录的相容真实面集合评测，不能先用任意单面标签制造失败。

若出现第一批未记录的活跃面，且它只能对应到不存在的内侧墙面，输出该窗口、真实几何和冲突原因。不要为保持零残差补造目标面。

## 4. 求解、筛选与导出

沿用原规格的加权正交 Procrustes、行列式分支、有效旋转、左右关节映射及速度计算。先冻结对应与权重，再计算候选；保留全部候选参数、残差、奇异值和筛选理由。旧位移只用于结果对照，不参与拟合或并列候选选择。

完成最小可用的活跃部件/面邻接描述，并用真实模型检查候选与成对组合：

1. 实际 FK 后的手表面与目标有限区域关系、合法面法向映射。
2. 非手部—物体及机器人—机器人穿透/间隙；明确精确几何或代理表示。
3. 源支撑时段中的脚部漂移与穿地、相对源运动的重力变化。
4. 关节限位、基座 SO(3)、真实 FK 与理想映射差异、姿态和速度连续性。

筛选阈值复用已冻结定义。仍缺定义时，在查看新候选结果前根据源参考、模型与任务需要记录 v0 判据；不以新结果反调阈值。Push 源参考已有手部穿透：同时报告旧、新的绝对值及变化，不能将已有问题自动归因于新构造，也不能用“源中已有”免除新增穿透。手部交互与非手部碰撞分别处理。

不要将正常迈步当作脚滑，也不要强迫 Pull 的倾斜动作保持直立。均沿用同一源支撑时段和坐标定义。用于候选筛选的数据与最终报告是否重合要说明，不把复用数据称为未参与选择的独立评测。

通过已定筛选后，按原规格选择组合并导出完整参考、runtime。无可行组合时保留候选和具体失败项；可导出清楚标注为 `diagnostic_only` 的最佳失败候选以解释问题，但不得标记为正式可用参考。

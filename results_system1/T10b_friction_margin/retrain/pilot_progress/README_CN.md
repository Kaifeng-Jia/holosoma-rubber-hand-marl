**口径：**
- **回合长度：**
  - 指窗口内结束的回合，按每轮的回合数加权。
  - 训练回合从参考里均匀随机抽的一帧开始（`PairedA1MotionCommand.reset`），所以不能和验证的总步数比。试点和原训练用的是同一规则。
- **终止：**
  - 四个 run 都只有两个终止项（`run_config` 的 `termination_terms`）：
    - `reference_horizon`，算作 timeout，即走到参考末尾；
    - `joint_bad_tracking`。
  - `joint_bad_tracking` 是一个终止项，包含三条：躯干重力 z 误差 > 0.8、物体位置误差 > 0.25 m、物体姿态误差 > 0.8 rad。训练日志不按这三条分开计数，原训练也一样。
- **奖励：**
  - `reward_mean` 含 PPO 的 timeout value bootstrap。
  - `Reward/env_raw_mean` 是 10 个奖励项加权、乘 dt 之后的和，不含 bootstrap。
  - `bucket_interaction` 的分项是这一项内部的量：位置、姿态、高度、relative 是 0–1 的得分；原始值 = 加权和 × gate。四个 run 的 gate 都是 1.0。
  - 另外 9 项（6 个运动跟踪项、动作变化率、关节限位、不期望接触）在训练日志里没有单独记录，原训练也没有。

- 物体位置误差 > 0.25 m，记为物体位置；

**终止段：** 第 2000 轮的第 302–348 步、第 4000 轮的第 315–349 步、第 6000 轮的第 314–354 步，都落在 261–414 帧的转动段里。
- 物体只由机器人 1 拿着，交接已在第 277 帧结束。
- 以第 302–348 帧为例（`validation_summary.csv` 的 `reference_kinematics_over_failed_steps`，另两段的数也在里面）：
  - 物体高 0.69–0.73 m，比初始高 0.32–0.36 m；
  - 物体平移 1.02 m，平均 1.11 m/s；转了 0.84 rad，偏航角从 −0.72 变到 0.07 rad；

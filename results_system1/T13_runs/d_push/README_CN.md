## 6. 和任务书的偏离、说明

- **±8 噪声关第一次启动失败：**
  - 现象：两个 Isaac 评测同时启动，同时把机器人 URDF 转成 USD，写到同一个缓存目录（`converted_rank0`）时冲突；±8 那个进程报 Fatal 后退出，返回码却是 0，输出目录是空的。
  - 处理：这次失败的记录移到 `_to_delete/t13v4_finals_d_push_pm8_try1_asset_race/`。启动器改成两个进程错开 90 秒启动，退出时核对写出的回合数是否等于状态数。±8 已重跑。
  - ±2 噪声关是改之前启动的，所以它的 exit 记录里没有回合数这一栏；它的 summary 有 51 个回合，完整。
- **评测脚本新加一个开关：**`--obs-v1-noise {off,on}`，默认 off，off 时行为不变（`records/code_switches.diff`）。
  - 冒烟：新代码在 off 下跑 nominal，和正式评测的 nominal 逐项相同，轨迹最大差 0。
  - on 时环境里的 v1 噪声状态确实打开。
- **MuJoCo 端新加的都是默认关的开关：**`mj_env` 的观测 v1，`mj_eval` 的 `--dump`、`--states`、`--obs-v1`，`onnx_check` 的 159 维 actor。
- **噪声开的 nominal：**±2、±8 两组都在第 210 步终止，冒烟里也是第 210 步。三次的噪声序列相同：评测种子固定为 241003，nominal 是第一个回合。
- **训练诊断只算到所用 checkpoint 为止：**训练日志一直记到第 6375 轮（停止规则生效后，训练还跑到验证结果回来）。只用 ≤ 6025 轮的 6000 行。
- **第 5 节第 5 条第 1 项"每台机器人手受力接触比例"在评测里没有做，原因如下：**
  - Push 的评测环境里没有手–物体力传感器，评测轨迹里也没有存力。
  - 要做，得在评测脚本里加记录接触力的开关，往评测场景里加传感器，不能事先保证模拟结果不变。已报 Kevin，等他决定。
  - 现在给的替代：训练日志里按台的同一指标（第 7 节），以及评测状态的几何接触比例（第 7 节）。
- **失败分类：**第 5 节第 4 条要求分"物体滑落 / 机器人摔倒 / 丢接触终止 / 其他"。
  - 评测协议只有一个终止项 `joint_bad_tracking`，失败原因按 T10 / T10b 的办法拆分。
  - 丢接触终止（第 2 条）是训练里的终止项，不在评测协议里，评测回合不会因为它结束，所以没有这一类。

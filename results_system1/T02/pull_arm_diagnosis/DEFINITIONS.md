# A 拉桌子手臂诊断：定义（2026-11-11 EST，Kevin 决定；写于计算 A、D 之前）

- **写之前看过的数据：** 只看了参考，没看 A、D 的轨迹。
  - 参考的手、肘位置由 V3 的 `BatchFK` 从参考骨盆位姿和关节角算出。与参考自带的肘、腕位置相比，最大差 3.0 mm。
  - 参考桌子沿桌子局部 −x 方向移动 0.584 m。
  - 参考桌子位移在第 100 帧首次超过 0.02 m。
  - 第 120–200 帧，每台机器人的两只手夹在它那一端近侧的桌腿两边：外侧手在桌腿的 +x 侧（离机器人远的一侧），内侧手在 −x 侧，高度在桌腿顶端附近。
- **范围：** Pull，±2 档，全部 51 个回合。
  - A：T01b 主设置。
  - D：V3 `Full`，种子 721/722/723。
  - 参考：同样的量也算一份，作对照。
  - 只读已有轨迹，不重跑。
- **几何：**
  - 桌腿取桌子 URDF `objects_widetable_plan5_pull_training.urdf` 的碰撞盒：0.05 × 0.3793 × 0.05 m，局部 y 向上。腿轴是竖直线段，局部 y 从 −0.368 到 0.011。
  - 每台机器人对应它那一端近侧的桌腿：机器人 0 对应 (x, z) = (−0.235, −0.674)，机器人 1 对应 (−0.235, +0.674)。
  - 手点 = `rubber_hand_link` 原点（与 V3 手部误差相同）。前臂 = 从 `elbow_link` 原点到手点的线段。
  - 所有位置都换到当前帧的桌子局部坐标里计算。
- **拉的方向：** d̂ = 参考桌子总位移在桌子局部坐标中的水平方向，即局部 −x。
- **相对位置（每只手）：**
  - 沿拉向偏移 a = (手 − 腿轴)·d̂。a < 0 表示手在腿的远侧，即"后侧"。
  - 横向偏移 b：水平面内垂直于 d̂ 的分量。
  - 高度 y：手在桌子局部坐标的高度。
  - "外侧手"是离桌子中心远的那只手，即 |z| 大的一只。机器人 0 是左手，机器人 1 是右手；这是按参考第 120 帧确定的。
- **"手在桌腿后侧"：** 外侧手同时满足三条：
  - a < 0；
  - 到腿轴的水平距离 < 0.12 m；
  - 高度 ≤ 腿顶端 + 0.05 m（局部 y ≤ 0.061）。
- **两个时刻：** 第 0 步（初始状态），以及受力阶段开始的第 t_f = 100 步（按参考桌子位移定）。A 或 D 在 t_f 之前就终止的回合，单独计数。
- **分开：**
  - 手臂–桌腿距离 = 该机器人两条前臂线段到腿轴线段的最小距离，减去腿的半宽 0.025 m。
  - 接触的近似：距离 ≤ 0.05 m。
  - "分开" = t_f 之后第一次距离 > 0.05 m、并持续至少 10 步或一直到回合结束的那一步。
  - 另报"外侧手离开后侧"：t_f 之后第一次 a ≥ 0 的步。
- **关节偏差：** 肩 pitch、roll、yaw 和肘，左右臂共 8 个关节，|q − q_ref|，参考取轨迹的 `reference_frame` 那一帧。
  - 受力前：第 1 到 t_f − 1 步。
  - 受力阶段：第 t_f 步到回合结束。
  - 每个回合、每台机器人、每个关节报两个阶段的平均偏差和两者之差。
  - D 另报一份"与 A 同一段步数"的值：第 t_f 步到 min(A 的终止步, D 的终止步)，A 取同一初始状态的回合。
- **说明：** 轨迹里没有手–物体接触力（这些回合没有接触传感器的数据），所以"接触 / 分开"都是按几何距离判断的近似。

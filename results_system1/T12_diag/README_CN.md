## 1. 力的核对（Isaac）

- **数据：** Isaac 轨迹里存了 `hand_object_normal_force_w`，即桌子上接触传感器对 4 只手的过滤接触力。顺序是 Robot 左手、右手，然后 Robot_1 左手、右手（`isaacsim.py:509-522`），与状态在同一时刻保存。
- **判定：** 一只手的 |F| > 1 N 算力接触。这个阈值和训练奖励里接触检测用的一样（`run_config.json` 的 `contact_threshold_n`）。
- **MuJoCo：** 轨迹里没有力的记录。

## 2. 参考：两台机器人的手到桌子的距离

- **阶段：** 用 T10b 的阶段标签。动作阶段（抬起、推、举起中、放下）共 314 帧，为第 190–503 帧；其余 372 帧是"静止"。

## 5. 数据来源

由子代理只读追溯。脚本复制在 `system1/t12diag/source_trace/`，结果在 `source_trace/`；各阶段的数已和结果文件核对。

- **谁是机器人 0：** 机器人 0 = CORE4D 序列 20231030/001（desk001，搬桌子）的 person1，机器人 1 = person2。
  - 原始数据在本机 `/home/kevin/datasets/CORE4D-V1-full/`。
  - 对应关系由几处代码共同决定：`core4d_adapter.py:347-350, 381-389`；`scripts/retarget_core4d_pair.py:516-524`；`scripts/export_core4d_small_table_pair.py`（qpos 按 person1、person2 的顺序叠起来）；`core4d_pair_runtime_reference.py:276-279`（`robot_a = robot_qpos[:,0]`）。
  - 数值核对：运行时参考 agent 0 的骨盆和关节，与 person1 的 Stage 1 结果一致（差 0）。
- **重定向流程：** 两人各做一次，配置相同。

  1. 坐标转换、15 → 30 Hz 重采样：两人相同。
  2. **逐人准备**（`core4d_retarget.py:119-209`），这是第一处按人不同的步骤：
     - 缩放 s = 1.32 / 身高：person1 是 0.74774，person2 是 0.73472。
     - 地面偏移：取该人脚部关节的最低 z。person1 是 +1.958 cm，person2 是 −1.897 cm，只从该人的关节上减去，桌子不跟着移。
  3. **两次独立求解（Stage 1）：** 每人在按自己缩放的桌子场景里求解。
     - 只用 22 个身体关节；手只用腕部位置，没有手指、手部朝向或接触吸引项。
     - 桌子设为硬性不可穿入，容差 1 mm。
  4. **共享场景合并**（`export_core4d_small_table_pair.py` 194-215，已复核），这是第二处按人不同的步骤：
     - 两人的 Stage 1 关节角保持不变。
     - 桌子取共同缩放 = 两人缩放的平均（0.741228），共同位移 = 两人桌子位移的平均。
     - 对 person1 来说，桌子缩小 0.87%，在搬运段平均位移 (+0.39, +0.61, −0.28) cm；person2 正好相反。
  5. 30 → 50 Hz 重采样，得到 687 帧的运行时参考：两人相同。

- **动作阶段的手到桌子的距离：** 正值为穿入，取较近那只手的中位值。原始人体数据用 SMPL-X 手部顶点到 desk001 网格的距离。

  | 阶段 | 机器人 0 / person1 | 机器人 1 / person2 |
  |---|---|---|
  | 原始人体数据（网格） | +0.76 cm，100% 在 1.5 cm 内，100% 穿入 | +0.77 cm，100%，100% |
  | Stage 1 输入（缩放和地面偏移之后） | +0.57 cm | +0.57 cm |
  | Stage 1 机器人（各自的桌子） | −0.33 cm，穿入 1.6% | −0.59 cm，穿入 0% |
  | 合并之后 | −0.61 cm，穿入 0% | −0.07 cm，穿入 44% |
  | 运行时参考 50 Hz | −0.62 cm，0% | −0.07 cm，43.6% |

- **整段（含静止段）在 1.5 cm 以内的比例：** 原始数据就是 58.5% 对 80.2%（桌子用盒子代理几何），和运行时参考的 58.5% 对 79.9% 相同。这个差别来自时间：person1 比 person2 晚约 1.7 s 碰到桌子，在 3.1 s 和 1.5 s。
- **抓法：** 两人都是从上方抓住桌子一端的边缘。
- **已有记录：**
  - 旧目录的 `logs/Core4DSmallTableA/comparison_20260920/RESULTS_CN.md:28-29` 已记录过两份策略里 agent 0 和 agent 1 的手接触比例不对等：19.88% / 0.92% 对 67.97% / 81.15%。

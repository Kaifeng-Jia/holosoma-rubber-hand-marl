## 1. 构造（和 9d 的差别）

- **抱起段 [0, w0) 和放下段 [w1, T)：**副本整个人（上半身、手掌也在内）= 原示范同一帧的 S 副本，加 9d 同样的水平平移 d_pre / d_post（四个脚点最小二乘对齐到倒放走路段的起点 / 终点）。
- **走路段：**不变，腿倒放，上半身跟着物体走（G）。
- **副本自己的箱子（我的实现选择，请看）：**在抱起、放下段跟着副本一起做 S 和平移，记作 Gp = Trans(d) S；走路段仍是 G。手掌目标的朝向也用 Gp 转。
  - 这样 S 副本拿着自己的箱子，姿态和原示范拿原箱子完全一样（冒烟测试在抽查的抱起、放下帧上验证过）。
  - 如果箱子还跟着物体走，上半身换成 S 副本后，手就不在自己的箱子上了。
  - 求解器里人一侧的物体系相对共享目标只差平移和小转角。三条调试片段 1.5 倍：转角最大 8.4° / 13.4° / 13.1°，9d 是 2.1° / 10.6° / 13.1°；平移最大 0.24 / 0.39 / 0.08 m。
- **其余同 9d：**S 绕世界竖直轴、过箱子中心转 180°，`--fb-human-frame target`，判定项和门槛不改。
- **开关：**`--fb-legs full_scopy`（默认关）。关时的构造和 9d 逐字相同：用新代码重新生成 9d 的门控文件，除新增的 r1_source 键外和 9d 存档相同。

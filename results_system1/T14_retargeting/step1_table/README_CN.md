## 4. 第 4 节指标的具体口径（`eval_table_refs.py` 开头）

- **几何：** 机器人用 PhysX 形状（T12-v2 的 `Robot('physx')`），桌子用 `desk001_5kg_training.urdf` 的五个盒子（精确盒并集距离）。
- **对应：** 机器人 0 对应 person1；源 15 Hz 的第 t 帧对应参考 30 Hz 的第 2t 帧。
- **接触保持率：** 条件帧是人手（任一 SMPL-X 手部顶点）离原始桌面网格 0.10 m 以内、且源物体速度 > 0.03 m/s 的帧，每只手 99 帧；其中机器人手的有符号距离 ≥ −0.02 m 的比例。
- **脚滑，两种口径都报：**
  - **任务书原文：** 支撑 = 人脚尖速度 < 0.01 m/s，滑动 = 机器人脚尖速度 > 0.01 m/s。这样只有 10 帧（r0）和 38 帧（r1）是支撑帧。滑动占比：现有 1.00 / 0.68，原样 1.00 / 0.71，新 0.90 / 0.79。滑动帧最大脚尖速度约 0.04 m/s，三者相同。
  - **OmniRetarget 代码：** 同一个 0.01，但单位是每帧米，30 Hz 时合 0.3 m/s。支撑帧 400 / 392，三份参考的滑动占比都是 0。
  - 两种口径的单位不同，如实并列。
- **CoCarry、GMR：** 没有对照 CoCarry 报告的 CORE4D → G1 数字（序列集合不同，本次只有一条序列），也没有尝试 GMR。

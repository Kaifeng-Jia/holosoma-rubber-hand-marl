## 1. 第 3 项：Table 1.0 的 1.19 cm 是怎么来的

对象：第 2 轮的 Table 1.0 参考，机器人 1，2.87 s（第 86 帧）。

1. **约束每帧都生效，但只在重定向自己的模型里。**重定向逐帧记录的最大穿透，两个人 413 帧都 ≤ 1.0 mm，弹性松弛全程为 0。
2. **约束和测量不是同一对几何，差在三处：**
   - **机器人运动学不同。**
     - 重定向用的 G1 是 `models/g1/g1_29dof.{xml,urdf}`，腰部两个关节的位置和仿真 URDF（`main_mesh_collision_rubberhand.urdf`）不一样：

       | 关节 | 重定向模型 | 仿真 URDF |
       |---|---|---|
       | waist_roll_joint | z 0.035 | z 0.044 |
       | waist_pitch_joint | z 0.019 | z 0 |

       躯干上的子节点各差 −0.010 来补偿，所以两个模型只在腰部伸直时一致。
     - 第 86 帧腰部有弯曲，肩到手整体偏 5.15 mm（x 1.09，y −4.47，z −2.32 mm），躯干坐标系偏 10.0 mm。
   - **机器人–物体的碰撞集合不同。**
     - 重定向：各连杆用 MJCF 自带的凸包，手用 PhysX 手凸包，另外还有拇指、小指上 1 mm 的标记小球，分别伸出手凸包 0.4 cm 和 1.45 cm。
     - 评测：全部连杆用 PhysX 形状，含头部。
   - **评测的深度量法不对。**第 1、2 轮取的是 mj_collision 里最深的接触点，这在部分盒子–凸包位形下并不是最小分离距离。
     - 第 86 帧左手：报告 1.19 cm，精确深度 0.45 cm。精确深度用 Minkowski 差算，和 mj_geomDistance 一致。
     - 整段的精确最大值：机器人 1 为 0.53 cm，机器人 0 为 0.18 cm。
   - **拆分：**1.19 cm ≈ 0.10（约束容差）+ 约 0.43（运动学差异）+ 约 0.66（量法高估）。
3. **修的过程中又查出 mujoco 版本的两个问题：**
   - **mujoco 3.10.0（`hsretargeting`）：**mj_geomDistance 对一部分实际分开 1–7 cm 的机器人–物体对，返回 0 或负值。3.3.7 也一样。
     - 第 2 轮 Table k = 1 的场景里，错的有 6/321 和 9/352 对（隔帧抽查），其中包括机器人 1 的手：实际离桌 1.4–3.9 cm，被判成贴着。
     - 后果：这会让约束挡住手、不让它靠近；值为负时，还会把连杆往外推。
     - mujoco 4.0.0 全部正确（0 错）。
   - **mujoco 4.0.0：**`np.int32 in (mjtJoint.mjJNT_HINGE, …)` 返回 False，但用 `==` 比较是 True。重定向在建 qdot→qvel 变换时用的正是 `in`，结果所有铰链列的雅可比都是 0。症状：手臂关节整段不动，Table k = 1.0 的接触保持率掉到 0.41。
     - 修正：比较前先转成 int，在 3.x 下结果逐位不变。
     - 复核：同一设定下，4.0（修正后）和 3.10 解出的前 100 帧逐位相同。
   - **两次作废的运行原样保留：**`logs_system1/t14/r3_mujoco310/`（3.10，受距离错误影响）、`logs_system1/t14/r3_mujoco400/`（4.0，修正前，雅可比为 0）。本返包的数字都来自修正后的运行。

## 7. 和任务书的偏离、需要说明的地方

1. **机器人–物体碰撞改用 PhysX 形状的范围。**不只是手，全部连杆都改用 PhysX 形状，头部也加上了；运动学也改成按仿真 URDF。这是为了让约束和测量成为同一对几何（第 3 条）。重定向还换了 mujoco 版本，并改了一处 enum 比较。这些都写在第 1 节。
2. **第 2 步的几处做法：**
   - 锚点按接触窗口分别取（每个连续接触段一个中位数），投影到这一档的仿真碰撞表面上。不投到原始网格，是因为仿真表面才是不穿透约束所用的几何。
   - 5 帧 smoothstep 过渡放在窗口内部的两端，窗口外为 0。
   - CoCarry 没有开源代码，这几处是按第 1 节文字所做的选择。
3. **哪些档做了第 2 步：**接触保持率 < 0.99 的档，共 Table 0.8 / 0.9 / 1.0、Bin 五档、Chair 五档。Table 1.1、1.2 和 Push、Pull 没做。
4. **超过 1 mm 的穿透，都出在橡胶手上：**
   - Table k = 1.2：0.39 cm；
   - Bin k = 1.2：2.34 cm，加第 2 步后 0.92 cm；
   - Chair k = 0.9 + 第 2 步：1.00 cm；
   - Push 0.36 cm，Pull 0.46 cm。

   重定向自己逐帧记录的穿透和评测一致（例如 Bin k = 1.2 机器人 1：都是 2.34 cm、第 280 帧），弹性松弛都为 0。所以这是线性化约束在每帧至多 10 次 SQP 迭代后剩下的非线性残差，不是几何不一致。没有改迭代次数等设定。
5. **机器人–机器人间隙只检查，不进优化。**
   - Bin 各档两台机器人都相交，−2.9 到 −5.7 cm。第 2 轮按精确量法是 −1.4 到 −2.7 cm，现有参考是 −1.1 cm。
   - 第 2 轮当时报告的正间隙用的是旧量法，不准。
6. **Push、Pull 的 a 按精确量法重新找过（第 7 节第 5 条）。**Push 从 0.70 变为 0.85，Pull 从 0.55 变为 0.65。
7. **运行用时（中位数 / 范围，秒）：**
   - 第 3 轮 36 个求解：210 / 106–484；

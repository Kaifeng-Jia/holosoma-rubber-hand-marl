## 1. 第 2 条：改了什么

- **新开关：**`frontback.build(..., walk_distance=...)`，命令行 `--fb-walk-distance {pelvis,pelvis_feet}`，默认 `pelvis`，等于 9g 原样。
  - 默认值重建 9g 存下的 gates，2 条片段 × 2 档逐项相同（`test_step9g2.py`）。
- **`pelvis_feet`：**
  - 走过的距离 x(t) = 骨盆、左踝、右踝三点沿走路方向 e 的水平位移的平均。
  - "两只脚"用的是踝（`L_Ankle`、`R_Ankle`）。
  - 倒放时间 tau 的算法不变，只是 x 换了：x(tau) = x(w0) + x(w1−1) − x(t)，x 先取累计最大值，保证单调。
  - 原示范和副本用同一个 x 的定义。副本一侧是倒放走路自己的骨盆和两踝。
- **没有变的：**
  - 固定平面 p_f 仍按骨盆算，倒放骨盆和镜像骨盆在走路段首尾两帧仍然重合；
  - 上身、骨盆、髋、共享物体轨迹、平面、两段腿逆运动学的算法都不变；
  - smoke test 核对过，改开关后副本只有踝、脚尖、膝变了。
- **判定：**
  - 非手穿透和两机间隙都用实际碰撞形状（第 1 条的判定 C）；
  - 其余判定项和档位协议照旧，"1.5 以上第一个不相交档"仍用碰撞形状的最小距离 < 0 算相交。

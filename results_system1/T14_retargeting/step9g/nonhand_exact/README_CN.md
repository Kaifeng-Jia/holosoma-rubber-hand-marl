## 1. 新旧两种量法

| | 旧量法（V0 原样） | 新量法 |
|---|---|---|
| 机器人一侧的形状 | 每个连杆碰撞网格（仿真 URDF `main_mesh_collision_rubberhand.urdf`）在连杆坐标系里的包围盒 | 求解器第二阶段约束和训练仿真用的 PhysX 连杆形状（T10 Isaac dump，23 个连杆，头的形状挂在 torso_link 上） |
| 运动学 | 仿真 URDF（yourdfpy） | 仿真 URDF（`contact_stats.Robot("physx")`） |
| 哪些连杆 | 两只橡胶手以外的全部 | 同左（21 个连杆，含头） |
| 物体 | URDF 里的碰撞盒 | 同左（盒子是精确的） |
| 距离 | 包围盒与盒子之间 `obb_sat` | `mj_collision` 在 0.1 m 内给出候选对，每对用 `mj_geomDistance`，和求解器约束是同一个函数 |

- **数值和门槛不变：**
  - 附加穿透 = 逐帧取（机器人进入共享物体的深度 − 源机器人同一帧进入源物体的深度），再取各帧最大值；
  - 门槛 ≤ 0.01 m；
  - 帧数和源求解都取该档评测命令里的。
- **源求解自身的穿透（新量法）：**最大 1.2 mm。9f 有 9 档 > 1 mm，第 8 步重跑和 9g 没有。
- **代码：**
  - `system1/t14/objects/nonhand_exact.py`：新量法；
  - `rejudge_nonhand_exact.py`：重判、出表；
  - 冒烟测试 `test_nonhand_exact.py`，4 项全部通过：
    1. 和求解器场景文件（`scene_sim.xml`）上独立算出的值一致，largeboxa 1.0 r1 都是 1.0 mm、左髋 roll、第 87 帧；
    2. 盒子放进骨盆时深度 > 5 cm，移到远处时为 −margin；
    3. 只碰到手的 2 cm 立方体不计入，关掉手的过滤后计入；

## 5. 其他判定项用的几何（只报告，没改）

| 判定项 | 量什么 | 几何 |
|---|---|---|
| 重力 | S 的线性部分和竖直方向的夹角 ≤ 5° | 不涉及形状，求解前算 |
| 支撑脚漂移（第 6 轮口径） | 人支撑段内，机器人脚的水平位移减去源机器人的，≤ 0.01 m | 机器人脚 = 踝 roll 连杆坐标系原点（仿真 URDF 运动学），不用碰撞形状；支撑段由人的脚尖关节速度定（`support.py`，σ = 8 平滑后 < 0.01 m/s） |
| 非手部位穿透 | 见第 1 节 | 现在改为 PhysX 形状 |
| 两机间隙（V0） | 两台机器人之间的代理距离 ≥ −1 cm | **仍是旧的包围盒代理**：每个连杆碰撞网格在连杆坐标系里的包围盒，含手，两台之间两两用 `obb_sat` |
| 接触保持率 | 人这边满足条件的帧里，机器人手到物体的有符号距离 ≥ −0.02 m 的比例 ≥ 0.99 | 机器人手 = 橡胶手的 PhysX 形状，对目标盒子的碰撞盒，`mj_geomDistance`。人这边的条件 = SMPL-X 手部顶点到采集物体网格的距离在 0.10 m 内，且共享物体速度 > 0.03 m/s |
| 主运动 | 骨盆 / 机器人根的水平净位移 / s > 1.0 m | 不涉及形状 |

- **只报告、不进判定的量：**
  - "两机最小距离"：两台的 PhysX 形状之间，`mj_geomDistance`；
  - "最大穿透"：所有连杆（含手）的 PhysX 形状进入物体的最大深度。
- **两机间隙判定和它报告的距离用的形状不同：**判定用包围盒代理，"两机最小距离"用 PhysX 形状。suitcasea 0.95 / 1.0 和 largeboxa 1.0 不过两机间隙，用的是包围盒代理。

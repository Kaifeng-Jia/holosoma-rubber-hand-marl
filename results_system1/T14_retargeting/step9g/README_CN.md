## 1. 新旧两种量法

两种量法的门槛（1 cm）和附加量的算法都一样，只是机器人一侧用的形状不同：

- **旧量法：**每个连杆碰撞网格在连杆坐标系里的包围盒，用 `obb_sat` 算深度。
- **新量法：**求解器第二阶段约束和训练仿真里用的 PhysX 连杆形状，用 `mj_geomDistance` 算深度。

详见 `nonhand_exact/README_CN.md` 第 1 节。其他判定项完全没动；它们各自用的几何也列在那份 README 的第 5 节。

## 2. 第 2 条的两个量（只报告，构造没改）

表：`feet_ik.csv`，脚本 `system1/t14/objects/step9g_feet_ik_table.py`。

- **核对：**每条片段都按 1.0 倍重建了构造，腿逆运动学的诊断和该档 `gates_m1p00.json` 逐项相同。
- **走路段腿被拉长的最大值：**
  - 定义：副本两段腿逆运动学里，镜像髋到倒放踝的距离减去大腿 + 小腿长度，取走路段各帧、左右腿的最大值。骨长用原示范自己的。大于 0 表示目标比腿长，腿被拉长。
  - 22 条里 20 条大于 0：最大 4.80 cm（sub10_largebox_086），其次 4.41 cm、4.07 cm、4.00 cm。
  - 单条腿被拉长的帧数，走路段最多 34 帧。
  - 两条小于 0（腿始终够得到）：sub4_suitcase_043 −0.26 cm，sub5_suitcase_046 −12.45 cm。sub5_suitcase_046 档位图上 3 个时刻都是蹲姿。
- **倒着走开头脚的单帧最大位移：**
  - 定义：副本人（求解器尺度）的左右踝、左右脚尖 4 个点，取相邻两帧位移里最大的一个点。"开头" = 副本走路段的前 15 帧（0.5 s）。
  - 22 条在 3.3–22.1 cm 之间：
    - 16 条出在走路段前 3 帧（+0 到 +3）；
    - 15 条就是整个走路段的最大值。
  - 对照，原示范自己走路段的最大单帧位移是 6.7–10.6 cm。
  - 这一帧跨过的源帧数在 0.5–11.5 之间。最大的是 sub4_suitcase_043（11.5）、sub17_suitcase_019（8.4）、smallboxa（7.6）、sub3_largebox_030（7.5）。
  - 解出来的副本机器人（1.0 倍，21 条；smallboxa 没解出来），同样 15 帧里两个踝 roll 连杆的单帧最大位移是 4.55–20.13 cm。
- **每条片段的完整数据在 `feet_ik.csv`**，包括左右腿分开的值、抱起段和放下段的拉长、整个走路段和整段的最大值。

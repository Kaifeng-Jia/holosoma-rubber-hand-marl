## 结论

**第二阶段**（机器人围绕共享目标求解；判定用的就是这一阶段的结果）：

- **覆盖 23 个连杆：**它们是带仿真碰撞形状（PhysX 形状，`physx_*` 几何体）的连杆。

  | 部位 | 连杆 |
  |---|---|
  | 骨盆 | pelvis |
  | 腿（左右各一） | 髋 roll、髋 yaw、膝、踝 roll（脚，7 块） |
  | 躯干 | torso（4 块）；头的形状挂在 torso_link 上 |
  | 手臂（左右各一） | 肩 yaw、肘、腕 roll / pitch / yaw、橡胶手 |

- **不覆盖：**
  - 髋 pitch、踝 pitch / intermediate、脚底 5 个球、腰 support、骨盆外壳、肩 pitch / roll、拇指和小指。
  - 这些连杆只有原始碰撞网格。原始网格 contype = conaffinity = 1，物体 contype = 4、conaffinity = 0，位掩码不相交，所以只和地面碰撞。
- **连杆集合和判定一致，形状不一致：**
  - 判定里"非手部位穿透"用的代理也是这 23 个连杆，手以外 21 个，头单独算一个。
  - 判定用的形状是每个连杆碰撞网格凸包的有向包围盒，比求解器的 PhysX 形状大。
- **不是严格的硬约束：**
  - role_solve 在第二阶段打开了弹性约束，穿透可以用松弛量换，代价是每米 1e5；
  - 容差 1 mm；
  - 只对每次迭代时距离 0.1 m 以内的对生效。

**第一阶段**（副本自己的初解，用默认配置，场景是副本自己的箱子 × s）：

- 全部 47 个机器人连杆的原始碰撞网格都覆盖。
- 是硬约束，没有松弛量，容差 1 mm。
- 9e / 9f 里报的"第一阶段 infeasible"，就是这里解不出来。

- **做法：**138 个评测档 × 2 台，共 276 条，在求解器自己的场景上用 `mj_geomDistance` 算，手以外的覆盖形状进入箱子最深多少，和判定的附加穿透对照。

## 1. 构造（开关 `--fb-legs reverse_warp`，默认关）

- **副本的人：**
  - 原示范整段（全身：上半身、手、腿、骨盆）按时间倒放；
  - 绕世界竖直轴、过目标中心转 180°（S）；
  - 再整体加一个水平平移 d（常数）。
  - 不逐帧平移，也不拼接不同来源的动作。
- **时间对齐 τ(t)：**原示范分成抱起 [0, w0)、走路 [w0, w1)、放下 [w1, T) 三段。走路段 = 第一个摆动段开始到最后一个摆动段结束，摆动段沿用筛选的定义。

  | 副本的段 | 取原示范的哪一段 |
  |---|---|
  | 抱起 [0, w0) | 倒放的放下段，帧 T−1 … w1 |
  | 走路 [w0, w1) | 倒放的走路段，帧 w1−1 … w0 |
  | 放下 [w1, T) | 倒放的抱起段，帧 w0−1 … 0 |

  - 每段首帧对首帧、末帧对末帧，中间线性拉伸或压缩；
  - 位置线性插值，关节转动用 slerp；
  - 某段源帧为空时，保持边界帧。只有 sub10_largebox_086 遇到：它没有抱起段（w0 = 0），所以副本放下段的 9 帧保持原示范第 0 帧。
- **副本自己的箱子：**取原示范的箱子在 τ(t) 的位姿，做同样的 S 和平移 d。所以副本拿自己箱子的姿态，和原示范在 τ(t) 拿原箱子完全一样。
- **平移 d：**最小二乘得到一个常数，让副本自己的箱子落在加长后共享箱子的另一端（逐帧差的平均）。
- **共享箱子：**
  - 平移用原示范的；
  - 转动取两个角色的中点（slerp，同 9c）；副本一侧的物体视角取 τ(t) 处的值。
  - 手的目标按箱子自身的对称映射到另一端（M1）。
- **支撑脚：**
  - 用倒放、对齐后的人脚尖轨迹算速度：σ = 8，< 0.01 m/s 判为支撑；锁定照旧。
  - 副本的接触标志和锚点也都取 τ(t) 处的值。
- **求解和判定：**
  - 第 6 轮 C，`--fb-human-frame target`，副本单独做第一阶段初解；
  - 判定项和门槛都不改。
  - 副本支撑脚漂移的对照源用 `--r1-source construction`：源解在 τ(t) 的脚位置（小数帧线性插值），再做同样的 S 和平移 d。
- **冒烟测试：**`test_step9.py` 里 `test_reverse_warp_time_map`、`test_reverse_warp_whole_body` 通过。

## 口径

- **mean_step_reward：** 即 `reward_mean`（与 V3 曲线导出的映射相同）。
  - 这是一轮采样中所有步、所有环境的平均回报，**包含超时自举**：超时那一步加上 γ·V，见 `src/holosoma/holosoma/agents/mappo/ppo.py:143`。
  - C 和 D 走的是同一份代码。
- **跟踪部分（只有 Pull 能算）：** dt × Σ wᵢ × `reward_terms_raw_mean[i]`，对 8 个跟踪项求和。
  - 身体 6 项：global ref position / orientation（权重各 0.5），relative body position / orientation、global body lin / ang vel（权重各 1.0）。
  - 物体 2 项：object global ref position / orientation（权重各 1.0）。
  - 不含正则项：action_rate、limits、undesired_contacts。
  - 权重来自 `g1_29dof_plan5_push_reward`，Pull 用的就是这一套；dt = 1/50 s。
  - **注意：** `reward_terms_raw_mean` 是每轮采样结束时那一步、所有环境的均值（`_reward_term_snapshot`），不是整轮的平均。所以它和 `reward_mean` 不是同一批样本。
    - 跟踪加正则与 `reward_mean` 的残差：中位数 C 为 0.8%，D 为 16%。
    - D 的残差多为正值，来源包括超时自举。逐项数字见 `pull_decomposition_check.json`。
  - "物体跟踪"一列只算那 2 个物体项。
- **Table、Bin：** 这套训练代码（core4d）不记逐项奖励，C 和 D 都一样，所以跟踪部分从日志算不出来。
  - 改报日志里有的两个跟踪相关量，**不等于跟踪部分**：
    - `Bucket/raw_reward_mean`：物体交互项的原始值；
    - `last_step_agent_ref_position_error_mean_m`：每轮最后一步机器人参考 body 的位置误差，越小越好。
- **取值：** 截止某次迭代的 100 次迭代窗口平均，即第 k−99 到第 k 次。
- **奖励设置：** C 与 D 相同。T01b F6 的 run_config diff 只有元数据、路径、存档间隔和 C 的动作包装 `system1_scheme_c` 不同。
